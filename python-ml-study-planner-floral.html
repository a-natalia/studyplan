The four stages

Weeks 1–2

Seed: Python foundations

Variables, loops, functions, lists, dicts and sets, file I/O, exceptions, modules, virtual environments, basic OOP, and argparse. Do 3–4 small exercises a day (Exercism, CodeWars, or Advent of Code).

Checkpoint 1

Weeks 3–4

Sprout: the data toolkit employers expect

  • JSON and JSONL: the json module, nested structures, validation with pydantic or jsonschema
  • Regex for text cleaning
  • NumPy and pandas: loading, filtering, grouping, merging
  • Git and GitHub: branches, commits, .gitignore
  • pytest basics and pinned dependencies

Kick off Project 2: choose your dataset and design the JSON schema.

Checkpoint 2

Weeks 5–6

Bud: ML fundamentals and classic NLP

  • scikit-learn: pipelines, cross-validation, logistic regression, random forest
  • Metrics: precision, recall, F1, confusion matrix, class imbalance
  • spaCy: tokenization, POS tagging, lemmatization, dependency parsing
  • TF-IDF and n-gram features

Checkpoint 3

Weeks 7–8

Bloom: transformers and shipping

Fine-tune a small pretrained model with Hugging Face transformers (DistilBERT or a multilingual equivalent), then wrap it in FastAPI. Docker basics are optional but valued.

Checkpoint 4

The two projects

Project 1: Text Statistics CLI

A command-line tool that reads any .txt file and reports token count, unique words, type-token ratio, average sentence length, and the top N words. It saves results to JSON and plots word rank against frequency, which shows Zipf’s law.

Builds: file handling, dictionaries, functions, argparse, json, matplotlib, simple tests.

Project 2: CEFR Proficiency Classifier for Learner Texts

Research question: which linguistic features (lexical diversity, syntactic complexity, error patterns) best predict a learner’s proficiency level, A1 to C2? Do they differ from what a transformer relies on?

What it shows employers: JSON/JSONL handling, data validation, pandas, spaCy, scikit-learn, Hugging Face, evaluation discipline, API design, Git, testing, and documentation.

Built a CEFR proficiency classifier for learner English using spaCy features and a fine-tuned transformer (macro-F1 X); exposed via FastAPI with JSON I/O; performed linguistic error analysis.
